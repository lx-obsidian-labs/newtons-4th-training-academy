# Product and engineering roadmap

> Engineering documentation maintained by [LX Obsidian Labs](https://lxobsidian.co.za). Project: Newton’s 4th Training Academy. Institutional content remains subject to academy approval and applicable rights.

## Gate 1 — Stabilise current release
Verify CI, direct route navigation, responsive layouts, keyboard and screen-reader use, handbook printing and external enquiry handoff. Obtain academy content approval.

## Gate 2 — Maintainability
Extract typed catalogue and reusable components, add behavioural and browser tests, measure performance, establish dependency review and capture approved screenshots.

## Gate 3 — Institutional services
Define roles, data retention, admissions state machine, authentication and private documents. Implement server-side access controls, database migrations and audit events. Test backup and recovery before production.

## Gate 4 — Academic operations
Introduce lecturer-managed lessons, assignments, assessment moderation and official records only after academic governance approval.

No dates or completion claims are implied. Each gate requires documented acceptance evidence and owner approval.
