# Learner and admissions user guide

> Engineering documentation maintained by [LX Obsidian Labs](https://lxobsidian.co.za). Project: Newton’s 4th Training Academy. Institutional content remains subject to academy approval and applicable rights.

## Find a programme
Open Programmes, filter by discipline or search familiar equipment names. Use Browse by picture if you recognise equipment but do not know its name. Select a programme for topics and enquiry options.

## Compare and shortlist
Use Compare to select two programmes. Save programmes in the visual directory to build a shortlist on this device. Clearing browser storage removes saved items.

## Prepare and learn
Open Resources for printable handbooks and the preparation planner. Use Learning to select a programme, answer all questions and review feedback. Practice completion is local and is not an official grade or certification.

## Enquire
Select a programme and use the admissions enquiry link. WhatsApp opens externally; sending a message does not constitute enrolment. Confirm fees, dates, prerequisites and certification directly with the academy.

## Troubleshooting
If a page fails, return to the homepage and retry. If local progress disappears, check browser storage settings. For incorrect course information contact admissions; for technical defects contact the developer through the website footer.
