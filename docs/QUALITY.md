# Quality assurance

> Engineering documentation maintained by [LX Obsidian Labs](https://lxobsidian.co.za). Project: Newton’s 4th Training Academy. Institutional content remains subject to academy approval and applicable rights.

## Release gates

- Repository integrity check and production build pass.
- Every catalogue title has unique visual metadata and learning topics.
- All programme links, query parameters and direct route refreshes work.
- Keyboard-only navigation, visible focus, screen-reader labels, 200% zoom and narrow viewport layouts are manually checked.
- Verify quiz scoring, retry, malformed localStorage recovery and shortlist persistence.
- Confirm WhatsApp handoff includes intended course and does not imply application acceptance.
- Check printed handbooks and prospectus for clipping, readability and accurate content.
- Confirm security headers and review dependencies for vulnerabilities.
- Academy reviewer approves programme facts, safety content, branding and legal notices.

## Evidence

Record date, commit, environment, browser/device, expected result, actual result and reviewer. Automated integrity checks are not equivalent to browser tests, WCAG certification, penetration testing or curriculum approval.

## Performance targets

Aim for Lighthouse performance and accessibility scores of at least 90 on representative mobile pages, with real-user Core Web Vitals in the good range. These are targets, not measured results.
