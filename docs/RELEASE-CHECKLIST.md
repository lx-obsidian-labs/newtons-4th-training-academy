# Release acceptance checklist

> Engineering documentation maintained by [LX Obsidian Labs](https://lxobsidian.co.za). Project: Newton’s 4th Training Academy. Institutional content remains subject to academy approval and applicable rights.

Record release identifier, commit SHA, reviewer, preview URL, production URL and date.

- [ ] Dependency installation and build pass.
- [ ] Catalogue and documentation checks pass.
- [ ] Direct navigation and refresh on all documented routes.
- [ ] Course search, comparison, shortlist and quiz interactions verified.
- [ ] Mobile and keyboard navigation verified.
- [ ] Public documents print correctly.
- [ ] Contact and enquiry handoff tested using synthetic data.
- [ ] Academy approves factual and safety content.
- [ ] Security headers checked on deployed responses.
- [ ] Previous deployment identified for rollback.
- [ ] Changelog updated and production smoke tests recorded.

Unchecked items are outstanding, not evidence of completion. Do not tag a verified release until acceptance criteria are met.
