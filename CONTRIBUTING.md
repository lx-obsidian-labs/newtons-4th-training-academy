# Contribution guide

> Engineering documentation maintained by [LX Obsidian Labs](https://lxobsidian.co.za). Project: Newton’s 4th Training Academy. Institutional content remains subject to academy approval and applicable rights.

Create a focused branch, document the problem and keep changes scoped. Use descriptive commits. Run npm run check and npm run build before opening a pull request. Include screenshots for visual changes and test evidence for functional changes.

When adding a programme, update catalogue data, visual metadata, learning topics and handbook content together. Verify technical terminology and obtain academy approval for claims. Do not invent fees, accreditation, certification or job placement promises.

Use accessible labels, semantic elements and keyboard-operable controls. Do not add unlicensed photographs or personal data. Document architecture changes and known limitations.
